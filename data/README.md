# Dataset Kelompok 3 — Steel Plates Faults

Sumber Kaggle: https://www.kaggle.com/datasets/uciml/faulty-steel-plates  
Sumber asli (UCI): https://archive.ics.uci.edu/dataset/198/steel+plates+faults  
DOI dataset: https://doi.org/10.24432/C5J88N  
Lisensi: CC BY 4.0 (cek sumber terbaru sebelum distribusi).

Data resmi berisi 1.941 baris, 27 fitur numerik, dan 7 kolom label biner one-hot. CSV lokal disimpan di `data/raw/faults.csv`.

Target: Pastry, Z_Scratch, K_Scatch, Stains, Dirtiness, Bumps, Other_Faults.

**Catatan:** Kolom `K_Scatch` memang menggunakan ejaan seperti pada dataset asli. Tidak boleh mengganti tanpa sinkronisasi seluruh modul.
